Smart Pillow – Snore Detection & Head Adjustment
📌 Description
This project is an Arduino-based Smart Pillow prototype designed to improve sleeping comfort by detecting snoring, adjusting the head position, and monitoring temperature.
🎯 Objectives
Detect snoring and provide an indication.
Adjust the user's head position based on pressure.
Monitor temperature continuously.
Demonstrate a low-cost smart sleep-monitoring system.
⚙️ Working
The system continuously monitors the user's condition. When the pressure value crosses a predefined threshold, the system adjusts the head position using a servo motor. When snoring is detected, an LED provides an indication. The temperature is also measured and displayed through the Serial Monitor.
🔧 Components
Arduino UNO
Servo Motor
Potentiometer (pressure simulation)
Push Button (snore detection simulation)
TMP36 Temperature Sensor
LED
220Ω Resistor
Breadboard and Jumper Wires
💻 Software
Arduino IDE
Embedded C/C++
Tinkercad (for circuit simulation)
🚀 Future Improvements
Replace the push button with a microphone/vibration sensor for real-time snore detection.
Replace the potentiometer with an actual pressure/FSR sensor.
Add Bluetooth/Wi-Fi connectivity for mobile notifications.
Store and analyze sleep data.
👩‍💻 Project
This project demonstrates the use of embedded systems, sensor interfacing, automation, and Arduino programming to develop a basic smart healthcare application.
